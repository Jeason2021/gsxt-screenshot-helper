# GSXT 企业信息截图助手 v1.2.2

仅在正常登录和验证后辅助人工采集国家企业信用信息公示系统的企业详情。不会自动处理验证码、绕过限流或连续抓取网站。

## 安装和升级（Edge）

1. 解压 ZIP 到固定目录。请保留原 v1.1.1 文件夹和 ZIP 作为备份。
2. 在 Edge 打开 `edge://extensions`，启用开发人员模式，选择“加载解压缩的扩展”，选中含有 `manifest.json` 的 `GSXT_Enterprise_Screenshot_Helper_v1.2.2` 文件夹。
3. 如要保留旧版 `chrome.storage.local` 进度，先导出旧版 CSV。将本版代码文件覆盖到**原扩展目录**后，点击“重新加载”，刷新已打开的官网页面。不要删除旧扩展或改换其目录；扩展 ID 改变时，原本地记录不会自动转移。确认弹窗和悬浮栏均显示 `v1.2.2`。
4. 在扩展详情中检查权限提示。`<all_urls>` 允许扩展在所有普通网站截图，范围大于业务网站；只有信任本扩展源码时才授权。`content.js` 只注入 `gsxt.gov.cn`，后台截图前再次核对标签页网址。

## 采集流程

1. 打开 `https://shiming.gsxt.gov.cn/corp-query-search-1.html`，按官网要求登录、验证、搜索。
2. 没有名单时，在官网用不同关键词正常搜索，再在扩展弹窗点击“识别当前搜索结果”。人工核对候选文本并“合并导入、自动去重”。也可导入 TXT/CSV 第一列的企业名称。
3. 点击“打开下一家”，确认搜索结果中的企业完全匹配，人工进入详情页。
4. 等营业执照信息加载后，核对悬浮栏中的企业名称，点击“保存当前页 JPG”。扩展**不会自动滚动**，保存你点击时的当前视口。要求同一屏能看到企业名称、统一社会信用代码和营业执照字段。视口容纳不下时，你可以自行滚动、缩小网页比例或扩大窗口再试。
5. 等下载完成后检查悬浮栏提示的**实际文件路径**和弹窗“已完成”计数。下载失败或实际文件名与企业名不符时，不计入成功。用“已完成企业”“失败企业”和“导出 CSV”核对进度。如果 Edge 只出现 `下载.jpg` 且计数增加，请先核对弹窗/悬浮栏是否确实显示 `v1.2.2`，避免仍运行旧扩展。
6. “暂停任务”只阻止打开下一家；正在进行的下载仍会结束。浏览器重启后本地记录保留。
7. 重复搜索、核对与保存，直到成功数量达到 500。可定期导出 CSV 备份记录，并与磁盘上的 JPG 文件逐一核对。

默认保存到 Edge 下载目录下的 `企业信息截图` 子目录。每家一张 JPG；若下载目录已有同名文件，浏览器可能生成 `(1)` 后缀，该次会标记失败并提示人工核对，扩展不会覆盖或删除原图。

## 选择路径与检查旧图片

- 在扩展弹窗的“JPG 保存位置”填写 Edge 默认下载目录下的相对子文件夹，例如 `企业信息截图/安徽`，点击“保存路径设置”。留空时直接保存到 Edge 默认下载目录。
- 需要选择 `D:\` 等任意绝对路径时，勾选“每张图片弹出另存为”；每次截图时由你在 Edge 对话框里选择目标文件夹。也可先在 Edge 下载设置中更改默认下载目录，再使用自动保存。
- 点击“扫描已有 JPG 文件夹”并选择已下载图片所在文件夹。扩展只在本地读取 JPG 文件名与 SHA-256；会报告重复文件名和**字节完全相同**的图片。扫描结果保存到扩展本地存储，后续截图会与之比对。文件夹新增或删除文件后，请重新扫描。
- 保存前还会比对已完成记录中的企业名称、统一社会信用代码、截图哈希，并检查 Edge 下载历史里可见的同名文件。浏览器下载历史的文件存在状态可能滞后；没有扫描过的磁盘目录不能被扩展直接遍历。不同编码或画面有细微变化的相同企业图片，不一定具有相同 SHA-256。

## 权限与截图范围

- `downloads`：保存 JPG、查询下载是否完成和取得实际文件名。
- `storage`：保存名单、完成/失败状态、暂停状态和采集记录。
- `<all_urls>`：`chrome.tabs.captureVisibleTab` 从网页内悬浮按钮调用时需要该权限或一次有效的 `activeTab` 授权。悬浮按钮点击不会授予 `activeTab`；当前交互方式因此保留此较宽权限。改为必须点击扩展工具栏按钮截图，才可能采用更窄的 `activeTab` 设计。
- `content_scripts.matches` 仅匹配 `https://*.gsxt.gov.cn/*` 和 `https://www.gsxt.gov.cn/*`。

`captureVisibleTab` 只截当前视口，不是整页拼接。代码在下载前验证 JPG 标记、尺寸及最低数据量，下载完成后核对浏览器报告的实际文件名；扩展无法直接再次读取磁盘文件，所以最终仍建议定期打开样本图片核查清晰度。

本扩展仅在自己发起当前 JPG 下载时再建议一次企业名。其他扩展若也处理下载文件名，仍可能覆盖建议；v1.2.2 会显示实际文件名并阻止错误计数。

## 已知限制

- 官网 DOM 可能变化，导致名称识别或搜索结果提取失败。识别不可靠时扩展会拒绝保存，需调整代码后重测。
- 不能自动完成验证码、实名验证或网站访问限制。
- 本版已在独立 Edge 的本地模拟页面验证截图不滚动、图像有效和保存子目录设置；未在已登录的真实官网页面完成验收。详见 `TEST_RESULTS.md`。
